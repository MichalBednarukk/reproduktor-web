# Reproduktor — wersja przeglądarkowa (PWA)

Webowa wersja gry Reproduktor. Działa 1:1 jak aplikacja na Androida z folderu `../app`.
Konfiguracja, mapa plików Android → web i sposób publikacji: [../NOTATKI.md](../NOTATKI.md).

```bash
npm install
npm run dev       # serwer deweloperski
npm run lint      # ESLint
npm run build     # sprawdzenie typów + build do dist/
npm run preview   # podgląd buildu: http://localhost:4173/reproduktor-web/
```
